# Roadmap

Status snapshot: 8 November 2026. These are proposed milestones, not completed capabilities or authorization to spend.

## 1. Prove a second real year

Bring the 1939 readings through the harness. Require source coverage accounting, explicit holds, preserved reader provenance, interrupted-run recovery, request-compatible reuse, release verification, and network-blocked replay. The latest retained project checkpoint records reading in progress; it is not a completed harness acceptance.

## 2. Improve the weakest evidence

Review unresolved fields and weaker-evidence settlements separately. Keep letter errors, punctuation differences, and row ownership distinct. Account for omitted pages before claiming a full year. Design an independent reference audit before making measured-accuracy claims; model agreement is insufficient.

## 3. Test layout transfer and total cost

Use an unseen year or materially different layout. Measure cost per accepted entry, including checking and repair, rather than first-pass token cost. A stronger model should earn its additional cost on difficult cases; a cheaper route must demonstrate adequacy before scaling.

## 4. Make review and reuse easier

The harness exports `UNCERTAIN-LINES-v1`; a reviewer interface is not implemented. Add source-linked inspection, traceable corrections, and separate search aliases without turning normalization into a silent source edit. Improve portable examples while keeping source rights and privacy explicit.

## Scope boundaries

No handwriting benchmark, autonomous agent society, model training, complete-year certification, or universal model ranking is claimed. General OCR and agent platforms may be components; task-specific evidence and acceptance rules remain explicit.
